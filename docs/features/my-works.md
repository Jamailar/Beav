# 我的作品

## 定位

我的作品放**自己的完整内容**：自己的账号（账号档案和已经发出去的作品），以及在 Beav 里写的每一篇稿件和它的各平台发布包。素材库是零件，参考库是别人的，我的作品是自己的成品。

## 入口

- 左侧「我的作品」：一个页面，没有二级侧栏。
- 聊天右侧工作区的「我的作品」标签：同样的内容，多了「全部 / 本次会话 / 待发布 / 已发布」筛选。
- 本机素材库网页 `/library` 的「我的作品」一行。

## 页面结构

- **顶部筛选**：按格式（图文 / 视频脚本 / 长文 / Post）和按平台（小红书 / 公众号 / X 等），只列出你有的。
- **我的账号**：每个自己的账号显示成头像 + 名字。双击打开账号页：上面是账号档案卡（头像、简介、粉丝数、定位标签），下面是这个账号已发的作品。最后一个图标「添加账号」。
- **稿件**：每篇稿件一张卡，默认显示最新的发布包；有两个及以上发布包（不同平台或不同版本）时叠成「一沓」，左上角写「N 个版本」，点开里面第一张是原稿，后面是各个发布包。还没打包的稿件直接显示原稿。可以建分类文件夹归类。

## 账号档案

- 贴主页链接添加（小红书、抖音、Bilibili、TikTok、Instagram 等；分享短链会自动解析）。
- 账号页可「同步最近作品」（选 1–10 页，按积分计费）；「设置 → 自动运营」里的账号档案定时刷新默认每天刷一次，并记录每篇作品的数据历史，日报的数据复盘就用它。
- AI 可以读档案和作品做账号分析、学习写作风格。

## 稿件与发布包

- **稿件**（原稿）：可持续编辑的正文，带稿件 ID、平台、阶段（初稿 / 终稿 / 已发布）。AI 只能标初稿或终稿，不会覆盖你的手动标注。
- **发布包**：某个平台某一版的快照，包含发布标题、正文和发布图片（或视频脚本）。稿件改了再交付会生成新版本，旧包不被覆盖。常见类型：小红书图文、公众号文章、视频脚本、X/微博 Post。
- **视频脚本包**：写口播稿、分镜、拍摄脚本时交付的包，有开头 3 秒、节奏条、分镜、按机位拍、提词器。
- 稿件卡右键：排期到某天 / 取消排期、标阶段、移动到文件夹。排期显示在主页的[内容排期](home.md)。

## 发布

Beav 不替你自动发帖，发布是「打包 → 领取 → 你自己发」：

- 发布包上的「发布」打开浏览器发布页：标题、正文各自可复制，图片可下载；「保存到电脑」导出图片、文案和发布页。
- 「手机扫码领取」：手机和电脑在同一 Wi-Fi，扫码在手机上保存原图、复制文案，再去平台 App 发布。领取链接 30 分钟有效。
- 公众号可以把文章发送到公众号后台草稿箱（需要授权）。
- 「标记已发布」只记录在本机，不会去平台发帖；每个平台、每个版本单独标记。

## 存放位置

稿件和发布包在空间的稿件目录里，每篇稿件有 `manifest.json`（含平台、阶段、计划发布日、发布记录）。文件位置不因为在「我的作品」里显示而移动。

## 和其他板块的关系

- 稿件来自[对话](chat.md)和[创作页](create.md)。
- 排期和发布状态汇总到[主页](home.md)。
- 别人的内容在[参考库](references.md)，自己能复用的零件在[素材库](materials.md)。
