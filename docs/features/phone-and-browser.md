# 手机互传与浏览器插件

## 定位

创作者的内容大多在手机上刷到、最后也在手机上发出去，而创作在电脑上。Beav 用局域网把两头接起来：手机刷到 → 存进电脑的参考库 → 电脑上创作 → 扫码回手机发布。浏览器插件则负责在电脑网页上一键采集。

## 手机上传（手机 → 电脑）

- 入口：参考库、素材库任一分类、商品页或本机素材库网页上的「手机上传」（手机图标）。弹窗显示二维码。
- 手机和电脑在同一 Wi-Fi（电脑可走有线同一局域网）。手机相机扫码，在系统浏览器打开；首次核对校验码后在电脑点「允许配对」，配对按电脑保存，在任一入口绑定过的浏览器从其他入口扫码都直接进入，默认 90 天有效。
- 手机页顶部切换：
  - **存链接到参考库**：粘贴各平台单篇分享链接（可带分享文案，一行一个，每批最多 50 个），电脑后台解析保存。
  - **传文件到素材库**：选图片、视频、音频（每次最多 20 个，单个 ≤ 1 GB），原格式保存到打开上传时的当前目录。
- 关掉二维码窗口后仍可上传，但电脑要保持 App 运行和联网。没有蜂窝网络远程上传。

## 分享到手机（电脑 → 手机）

- 发布包：「手机扫码领取」打开领取页，保存原图、复制标题和正文，再去平台发布。视频脚本包打开的是视频脚本页（可当提词器）。
- 素材、图片、视频：卡片或预览上的「分享到手机」，手机上查看、播放、下载；文件夹打包成 ZIP。
- 二维码和链接 30 分钟有效，只能领取选中内容的快照，不需要配对；只在可信局域网使用。

## 浏览器插件（Chrome / Edge）

- 从官网或 GitHub Release 获取，加载到 Chrome / Edge。插件只在官网推广，App 内不引导安装。
- 在小红书、抖音、YouTube、公众号和普通网页上一键「保存到 Beav」，把图片、视频、文案和评论采集进参考库。
- **浏览器连接**：连接后 Beav 的 AI 可以用你已登录的浏览器搜索、逐条打开内容并保存，适合大量定向采集；验证码和首次确认由你处理。
