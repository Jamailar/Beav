# 对话与右侧工作区

## 定位

对话是 Beav 的主工作方式：写稿、仿写、找选题、生图、做视频、配音、剪辑、打包发布，都是在对话里告诉 AI，由 AI 调用工具完成。没有单独的「图片创作页」或「视频创作页」。

## 入口

- 左侧「新对话」打开空白对话；左侧栏中部是这个空间的对话列表（只有一行「对话」小标题，稿件已移到「我的作品」）。
- 从主页的日报、选题、会话看板，创作页的模板，参考库的「AI 仿写」，热点的「AI 讨论」等地方，也会新开或打开一个对话。

## 新对话页

空白对话的输入框上方有两排起手预设，下方是创作模板：

- **平台**：默认是空间设定的创作平台，选中上次用过的；「更多」可临时换平台，只对这个对话生效。选中的平台随第一条消息发出，AI 按该平台规格写。
- **场景**：随平台变化，例如「找选题」「拆爆款」「图文笔记」「口播脚本」「数字人口播」「剪视频」「写长文」「公众号排版」「写动态」「封面配图」「推广商品/店铺」；素材库 `prompts/` 里有提示词时出现「我的提示词」。点场景后换成几句示例，`【】` 是要填的空位，Tab 跳到下一个空位。选了场景会挂上对应技能，并在这个对话里持续生效。
- **创作模板**：图片、封面、小红书、视频模板，可按行业和类型筛选；也可以用一张图「创建模板」。见[图片、视频、配音与模板](media.md)。

## 给 AI 提供资料

- 从右侧工作区把参考库、素材库、我的作品里的卡片拖进输入框，变成引用卡片；输入 `@` 选择技能、商品、数字人等。
- 粘贴、拖入或选择图片和文件作为附件。附件只属于这条消息，不会自动进素材库。
- 语音输入：点麦克风录音（最长 5 分钟），转写成文字填进输入框，再手动发送。
- 未发送的文字和引用卡片按对话保存在本机草稿里。

## 运行中

- 输入框里可以选模型，重新打开对话会恢复这个选择。每条回复底部显示本次消耗的积分。
- AI 运行时继续发的消息进入「待发送队列」，可「引导」（在安全点交给 AI，不打断正在执行的工具）、编辑或删除；点停止会保留队列。
- AI 需要你回答时，会在输入框上方出现问题卡片；需要授权的操作会弹出确认。
- 长对话会自动压缩上下文，可以一直接着聊。
- 对话可以派出并行的子 Agent 处理子任务，结果回到主对话。

## 右侧工作区

聊天标题栏右侧的按钮（或 ⌘K / Ctrl+K）展开右侧工作区。它像浏览器一样用标签页，「+」可打开：

- **素材库 / 参考库 / 我的作品**：和左侧三个库是同一套内容的窄版，可以浏览、搜索、拖进对话。我的作品标签有「全部 / 本次会话 / 待发布 / 已发布」筛选；「本次会话」集中展示这个对话的附件、生成结果、发布包和链接，可以勾两张图并排比较。
- **视频剪辑**：完整的剪辑器，见[视频剪辑器](video-editor.md)。
- **浏览器**：内置浏览器，多标签、缩放、「引用到对话」；登录状态按空间分开保存。

对话里出现的文件、图片、发布包也在右侧以标签打开。标签和展开状态按空间和对话保存，重启后恢复。

## 对话的去向

- 首页「会话看板」按「等你处理 / 待查看 / 进行中」显示对话，见[主页](home.md)。
- 归档对话后顶部有约 5 秒的「撤销」，之后可在设置里找回。
- 对话产出的稿件和发布包在「[我的作品](my-works.md)」，生成的媒体在素材库的「生成记录」。
