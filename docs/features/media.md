# 图片、视频、配音与模板

## 定位

Beav 没有单独的媒体创作页面。图片、封面、视频、配音、字幕都在[对话](chat.md)里完成：说明用途、平台、比例和参考素材，AI 选择合适的工具和模型去做。生成会消耗积分，或使用你配置的外部服务。

## 图片与封面

- 直接描述画面，或附上参考图（粘贴、拖入、从右侧素材库拖入）。
- 小红书封面会参考多类构图方向结合内容选择；完整图文没有一次性授权时，AI 默认先做两张给你确认再做剩下的。
- 可以让 AI 检查已有图片的局部（文字位置、是否遮挡），不改原图。
- 生成结果进素材库的「生成记录」，用得上再收藏。

## 视频

- 直接描述想要的视频，AI 按当前视频模型生成；或用视频模板（工作流），弹窗里能看到每个节点的状态和中间产物，失败节点可单独重试。
- 图片 + 配音 + 字幕做成的视频、科普讲解视频，AI 会建一个可编辑的剪辑工程，见[视频剪辑器](video-editor.md)。
- **数字人口播**：用素材库里的数字人，先出 480P 对口型预览，确认后出 1080P，见[素材库](materials.md)。
- **做同款**：基于参考库里拆解过的视频，按同款配方安排「数字人出镜（A 段）+ 画外画面（B 段）」，先给一条完整时长的低清粗剪确认，再出成片。
- 可以让 AI 看参考视频的指定时点或一小段，不必专门建工程。

## 配音与字幕

- 对 AI 说文稿、语言和音色，或用「AI 配音」小工具（分段设置语言、音色和停顿）。音色包括各模型的系统音色和你克隆的音色；克隆的音色属于账号，不绑定某个模型。
- 定稿里易念错的词（数字、折扣、多音字）AI 会标读法：配音按读法念，字幕显示原文。
- 转写用「音视频转文字」小工具，可导出 TXT、SRT、VTT、JSON。

## 两类模板

| | 新对话页下方的「创作模板」 | 左侧「创作」页的内容模板 |
| --- | --- | --- |
| 偏重 | 视觉风格（封面、图片、小红书、视频工作流） | 整条内容的结构、节奏、句式和风格 |
| 来源 | 在线模板市场（公共）+ 用一张图创建的个人模板 | 从参考库的内容拆解后做成 |
| 用法 | 选模板 → 补主题和参考图 → 发送 | 选模板 → 填表单 → 开始做 |
| 文档 | 本页 | [创作页](create.md) |

公共模板不随安装包携带，第一次使用需要联网，之后先显示本机缓存。官网模板页的「在 Beav 中使用」会把模板带进新对话输入框，不会自动生成。

## 其他媒体能力

- 去 AI 水印（只清理文件元数据）、图片转 Live Photo（本地动效）、链接素材下载、视频文案提取：见[工具&技能](tools-and-skills.md)的小工具。
- 图片和视频供应商版本、结果恢复：提交成功不等于生成完成，结果未知时 Beav 保留失败信息，不自动再次生成，避免重复扣费。

## 找结果

- 生成的图片、视频、配音、剪辑导出：素材库「生成记录」。
- 某个对话的所有产物：右侧工作区「我的作品 → 本次会话」。
- 切换空间后任务继续在原空间跑，结果存回原空间。
