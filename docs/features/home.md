# 主页

## 定位

主页是每天打开 Beav 先看的地方：今天该做什么（日报和选题）、哪些对话在等我（会话看板）、内容排到了哪天（内容排期）。只在 Agent 模式里有。

## 入口

左侧「主页」。

## 组成

### 运营日报

- 默认每天 09:00 在本机生成（App 关着时不生成）。生成会消耗积分；上一期还没在主页打开过时，下一期自动暂停，不扣积分。
- **今日选题参考**：AI 从新闻、NewsBing 热点、订阅博主的新内容、对标案例和账号规划里找出的选题建议，每条可「开始制作」（开一个对话去做）、讨论或放弃。
- **今日数据复盘**：自己账号昨日或最近可比区间的数据和结论（依赖账号档案的每日刷新）。
- 标题旁可切换日期、设置「关注」的来源；底部「聊聊这期日报」开一个讨论对话。

### 会话看板

把对话按「AI 能不能不靠你继续」分成三列：

- **等你处理**：AI 停下来等你回答（选择、补充信息、登录授权、它解决不了的错误），卡片写着它的问题。
- **待查看**：任务做完了，等你验收，卡片写着交付了什么；点「验收完成」即结束。
- **进行中**：AI 正在做。

已完成和归档的对话不在看板上。点卡片在主页右侧直接继续这个对话。稿件全部标为已发布的对话自动归入已完成。

### 内容排期

- 月 / 周 / 年视图（默认周），显示每天排期的稿件、当天的产出（发布包、稿件、图片等）、节日和定时任务。
- 颜色：灰色初稿、橙色终稿、绿色已发布、红色过了计划日还没发布。
- 「＋ 排一篇」从未排期的稿件里选一篇排到某天；稿件可以在日历里拖到另一天。点节日或营销节点会开一个借势选题对话。
- 右上角放大进入完整日历：右侧「待排期」列出未排期稿件可直接拖入，「运营任务」标签管理周期任务。
- 计划发布日只记在本机稿件记录里（稿件 `manifest.json` 的 `plannedPublishDate`），不会到点自动发布。

### 选题池

当前空间选题中心里的选题，可记录灵感、继续讨论、开始做或放弃。选题也出现在素材库的「选题」分类里，来源包括日报、拆解、热点、参考库卡片「存为选题」。

### 常用小工具

主页保留常用小工具的快捷入口和「查看全部」，见[工具&技能](tools-and-skills.md)。

## 自动运营与扣费

日报、周期任务、账号档案定时刷新、订阅博主定时刷新这类「你没操作也会花积分」的任务，统一在「设置 → 自动运营」管理。有自动任务花了积分、失败或正在运行时，左侧账号按钮上方会出现一行小字（例如「自动消耗 12 积分」），点开能看到每一笔。见[账号、设置与记忆](account-and-settings.md)。
