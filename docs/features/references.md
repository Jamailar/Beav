# 参考库

## 定位

参考库放**别人的完整内容和别人的账号**：收藏的单篇内容、订阅博主自动抓到的内容，以及对它们的拆解。它是「看别人怎么做」的地方，也是 AI 仿写、做同款、做模板时的依据。

自己的内容不放这里：自己写的稿件和自己账号已发的作品在[我的作品](my-works.md)。

## 入口

- 左侧「参考库」。
- 聊天右侧工作区的「参考库」标签。
- 本机素材库网页 `/library` 的「参考库」一行。

## 页面结构

参考库没有二级侧栏，整页就是一个画廊，顶部三个视图切换：

- **画廊**：瀑布流卡片，按添加时间倒序。卡片按平台用原生样式（小红书是封面 + 两行标题 + 作者和点赞，公众号是横向封面等）。
- **时间轴**：一行一条。
- **博主**：每个保存过内容或已订阅的博主一个头像，带平台角标、条数，以及「已订阅 / 已暂停 / 对标」标签和未读数。双击进入博主页。

画廊第一个位置永远是虚线的「新建」卡：粘贴链接保存内容，卡上还有「手机上传」「订阅博主」。第一次打开时顶部有一张说明卡。

## 收进来

- **贴链接保存单篇**：小红书、抖音、Bilibili、YouTube、X、微博、知乎、微信公众号、视频号、Instagram、TikTok 等单篇链接，可连同分享文案粘贴。YouTube 要在电脑上选清晰度并确认积分后才下载。保存失败会在后台自动重试，失败卡片可手动重试。
- **手机分享**：手机上复制链接，在手机页「存链接到参考库」，见[手机互传](phone-and-browser.md)。
- **浏览器插件**：在网页上一键「保存到 Beav」（插件只在官网推广，App 内不引导安装），见[浏览器插件](phone-and-browser.md)。
- **对话里让 AI 找**：AI 可以用社媒调研或已连接的浏览器搜索并保存内容（会先说明积分消耗）。

## 订阅博主

- 在博主页点「订阅」，或用新建卡的「订阅博主」贴主页链接。订阅后每天自动检查一次新作品，刚订阅时先导入最近 10 篇。
- 按调用次数扣积分（没有新作品的一天扣 1 次，每天最多十几次），弹窗里写明当前单价；暂停或删除后不再扣。用自己的 TikHub Key 时不扣 Beav 积分。
- 订阅数到 3、5 个时有提醒，最多 10 个。
- 博主页可「停止订阅 / 恢复订阅」「立即检查」「设为对标」「删除博主及内容」。
- 订阅不会自动拆解。

## 拆解

拆解只在你手动点的时候进行：条目详情里的「拆解」按钮、列表多选后右键「拆解选中的 N 项」（一次最多 100 条），或在对话里让 AI 拆。拆解在后台排队，按积分计费（转写、对话、视频理解模型）。

拆解结果：

- **选题**：选题、切入角度、受众、痛点、开头钩子，同时加入选题中心。
- **结构**：各段作用和时间点，以及可套用的结构模板。
- **镜头**：按画面切换切分，每镜缩略图，可手动「并入上一镜」「从播放处切开」；顶部是镜头数、平均镜长和节奏带。
- **配乐片段**：没有人声的段落。
- **拍摄脚本**：逐镜景别、运镜、机位、画面、字幕、声音。
- **原文案**：带时间戳的逐句文案。
- **碎片**：拆出的片段、配乐、封面、图片、文案留在条目里（`derived/fragments/` 等），每个碎片可单独「存入素材库」。

给 AI 用的部分（界面上看不到，AI 读得到）：

- **同款配方**：逐镜标注画面来源（真人口播、实拍、空镜、录屏、字卡、AI 生成等）、按「画面段」整理的台词和原片片段、实测节奏，用于「做同款」。
- **形式迁移理解**：哪些是固定的形式（句式、结构、节奏、版式，必须保留）、哪些可以换（主题、知识点、案例）、哪些是原作者的主体和它们出现的位置（人、品牌、数据、原素材，不能带走）。用于[创作页](create.md)做模板和仿写。
- **风格学习**（视频）：画面组成、字幕版式、动画、画风、剪辑节奏，带参考帧。

## 用起来

- 详情里「AI 仿写」开一个仿写对话；仿写默认高度相似，保留题目句式、页序、论点和图片风格，只换成你的领域内容。
- 右键「做成模板」进[创作页](create.md)；右键「存为选题」进选题中心。
- 在对话里拖入或引用条目，AI 能看到它有没有本地原视频、有没有拆解。

## 和其他板块的关系

- 拆解出的碎片 → [素材库](materials.md)。
- 拆解 → [创作页](create.md) 的模板。
- 订阅博主的新内容 → [主页](home.md)日报的选题参考。
- 自己账号的档案不在这里，在[我的作品](my-works.md)。
