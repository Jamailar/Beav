# 素材库

## 定位

素材库放**自己的、可以拿来做内容的零件**：图片、视频片段、文案片段、配乐、提示词、选题、数字人、商品与店铺，以及导入的电脑文件夹、Obsidian 仓库、Eagle 素材库。它是普通文件夹，可以像访达一样整理；AI 和外部 Agent 创作时也从这里取素材。

完整的内容不放这里：自己的稿件在[我的作品](my-works.md)，别人的内容在[参考库](references.md)。

## 入口

- 左侧「素材库」。
- 聊天右侧工作区的「素材库」标签（窄版，分类做成胶囊）。
- 本机素材库网页 `http://127.0.0.1:31937/library`，见[接入外部 Agent](external-agents.md)。

三处内容和操作保持一致。

## 页面结构

左栏从上到下：

1. **全部素材**：按文件夹浏览素材库根目录。
2. **八个分类**（只是筛选视图，不移动文件）：
   - **商品**：商品卡和店铺卡（见下）。
   - **图片**、**视频**：所有文件夹里的图片、视频，最新的在前。
   - **文案**：所有 `.md` / `.txt`（`prompts` 里的除外）。
   - **配乐**：只收标为配乐的音频（拆解切出的配乐片段、在配乐分类里导入的、右键「标为配乐」的）。AI 配音不算配乐。
   - **提示词**：根目录的 `prompts` 文件夹，提示词以文字卡显示，一键复制；新对话的「我的提示词」场景也从这里读。
   - **选题**：选题中心里没放弃的选题，可「继续讨论」「开始创作」。
   - **数字人**：见下。
3. **生成记录**：AI 生成的图片、视频、配音、剪辑导出（见下）。
4. **已导入**：导入的电脑文件夹、Obsidian 仓库、Eagle 素材库，点一下直接浏览里面的内容。

每个分类的第一张是「新建」卡片。第一次打开时顶部有一张说明卡，讲怎么放进来（拖文件、新建卡、手机上传）、怎么找、怎么在聊天里用。

## 文件操作

- 单击预览，双击进文件夹；Command/Ctrl、Shift 多选，框选，拖动移动；右键重命名、移动、移到废纸篓、打开所在文件夹。
- 从访达 / 资源管理器拖入或粘贴文件，按副本导入，原文件保留，同名另存。
- 「手机上传」把手机里的图片、视频、音频传到当前目录，见[手机互传](phone-and-browser.md)。
- 单个素材可以「分享到手机」，扫码领取原文件。

## 拆解合集

参考库里拆解出的镜头、片段、文案、配乐默认留在参考库条目里，逐个「存入素材库」后才进来。历史上拆解写入素材库 `decompositions` 的内容，在各分类里折叠成一张「拆解合集」卡片（图片分类是一叠照片、视频分类是一卷胶片、配乐分类是一张专辑），双击展开。素材预览的「来源」能回到原内容。

## 生成记录

AI 生成的东西大多只用一次，所以不直接进素材库，而是放「生成记录」：按天分组，可搜索、预览、拖进对话或剪辑器。用得上的点星标「收藏」（或右键「收藏到素材库」）移进素材库；反过来素材也能「移到生成记录」。

- 文件实际在素材库根目录的 `ai-outputs/YYYY-MM/`，这个文件夹不在首页显示。
- AI 和外部 Agent 搜素材时默认不搜生成记录，用户说「刚才生成的」才去找。
- 生成记录不会被自动删除。

## 商品与店铺

想推广自己的商品或门店时，把商品照片、商品页截图、门店照片交给 AI，它会认出有几个商品、分好组、读出价格和卖点，确认后存成卡：

- **商品卡**：`products/` 下的复合资产（类型 `product`），含真实照片、价格、卖点、适合人群、规格、不能说的话。
- **店铺卡**：也在 `products/`（类型 `store`），含门头、店内照片和地址、营业时间。商品可以归到某家店。
- 「商品」分类顶部切换「商品 / 店铺」视图；商品卡上「用它写内容」直接开对话。
- 建卡入口：任意对话里丢图、新对话的「推广商品/店铺」场景、「商品」分类的新建卡。
- 每轮对话 AI 都知道最近的商品和店铺清单；写推广内容时只用卡里的事实，不编价格和功效。用 `@` 或决策模型选中的卡会以「本对话一直带上」胶囊挂在输入框上方。

## 数字人

「数字人」分类里建自己的数字人，用来做口播视频：

1. **照片**：1–9 张正脸照片；也可以上传视频或贴视频链接，从视频里取画面（多角度参考照会一起发给视频模型认清长相）。
2. **声音**：现场录约 25 秒或上传 15–60 秒音频，勾选本人或已授权；保存后后台克隆音色，约 1 分钟。
3. 详情里可设默认情绪、语速、音调、画面比例，输入一句话试听。

用法：在详情点「用 TA 做口播」，或在对话里说「用小林做一条 30 秒口播」。AI 先用 TA 的声音配音并核对读错，再出 480P 对口型预览，确认后出 1080P 成片。数字人存在 `assets/characters/digital-human-xxxxxx/`。声音属于账号，不绑定配音模型。

## 和其他板块的关系

- 参考库拆解出的碎片可逐个存入素材库。
- 对话、创作页、剪辑器、外部 Agent 都从素材库取素材。
- 素材库模式就是把 Beav 只当素材库用，见[接入外部 Agent 与素材库模式](external-agents.md)。
