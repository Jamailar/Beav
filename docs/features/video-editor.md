# 视频剪辑器

## 定位

Beav 内置一个完整的时间线剪辑器，开在对话的右侧工作区里：左边和 AI 对话，右边是剪辑器。AI 能看到当前工程、选中的片段、播放头和 I/O 范围，可以直接改时间线；你也可以手动剪。最常用的是「智能剪口播」。

## 入口

- 右侧工作区「+」→「视频剪辑」，选最近的工程或「创建工程」。
- 或者直接在对话里给视频并说怎么剪，AI 自己创建或打开工程。

每个对话记住自己的工程；关闭「视频剪辑」标签即退出剪辑。

## 智能剪口播

讲解、课程、访谈、带旁白的录屏，只要语音是主线都按口播处理。说「帮我把这段口播剪干净，加字幕」即可：AI 转写视频，删口误和停顿，划分语义字幕，安排人物画面、补充画面（B-roll）和解释动画。

- 各分析步骤的方案单独保存，可以在方案弹窗里改了再应用，不用重新分析。
- 画中画可能先放可替换的占位，之后换成工程素材、素材库或参考库的素材。
- 中断后工程、转录和方案都在，继续时不重复应用已执行的剪辑。
- 有定稿时，字幕文字用定稿原文，时间取语音识别结果。

## 让 AI 改指定内容

选中片段后说目标，例如「把选中字幕改为白字黑边」；也可以描述时间段或对象。AI 的修改进入撤销历史。指定「只处理 I/O 范围」时范围外不动。

## 手动编辑

- 时间线：点选、拖动、裁剪、框选；预览里点字幕或画面也会选中对应片段。键盘剪辑、插入/覆盖、修剪模式（波纹、滚动）、变速拉伸、目标轨。
- 素材导入只是「可用」，放到时间线上才出现在画面里。
- **文字**：花字库（几十个预设）、立体字、霓虹/故障/金属等文字特效、拱形波浪等变形、入场出场动画；口播风格模板。
- **声音**：人声增强、电话、回声等声音效果；有人说话时自动压低音乐；内置音效库（转场、点击、提示音等短音效）。
- **内置动画**：口播叠加（重点大字、人物介绍、数字强调等）和图形装饰（箭头、圈画等），离线可用。
- **特效**：画面特效和镜头动效（推近、呼吸等），本机计算。
- **AI 解释动画**：需要展示关系、流程时，AI 用 Remotion 做图形动画并按口播时间放进时间线（需先在工具&技能安装 Remotion 插件和本机 Node 环境）。
- 字幕、花字使用 App 内置字体，各平台外观一致；支持多语言文字（含阿拉伯语、泰语）。

## 导出与版本

- 导出在后台进行，提交后可以继续剪；导出用的是提交时的工程快照。导出文件进素材库「生成记录」。
- 工程自动保存版本，可从撤销/重做菜单恢复（恢复生成一个独立副本）。
- 标题栏「反馈问题」可提交剪辑问题，默认附带脱敏日志。
