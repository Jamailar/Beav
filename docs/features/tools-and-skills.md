# 工具&技能

## 定位

「工具&技能」是给 Beav 加能力的地方：可以直接打开用的小工具，给 AI 的工作方法（技能），可安装的能力包（插件），以及外部工具服务（MCP 连接）。

## 入口

左侧「工具&技能」，默认显示「小工具」标签，另有「技能市场」和「插件」。主页也有常用小工具的快捷图标。

## 先分清四个概念

| 名称 | 是什么 |
| --- | --- |
| 技能（Skill） | 给 AI 的可复用工作方法和参考资料（`SKILL.md` + 参考文件），按需读取 |
| 工具 | AI 读取状态或执行动作的能力，有参数和权限边界 |
| 插件 | 可安装的能力包，可以包含技能和 MCP 服务器 |
| MCP 连接 | 连接外部工具服务的配置，可由插件提供，也可单独添加 |

「插件已安装、连接已配置、账号已授权、工具在当前任务可用」是四个不同的状态。

## 小工具

独立窗口打开的小应用，可同时开多个，可按「全部 / 内置 / 我创建的」筛选。内置的有：

- **视频文案提取**：批量从抖音、视频号、TikTok 链接提取文稿。
- **链接素材下载**：下载链接里的图片、视频。
- **音视频转文字**：选转写模型，导出 TXT、SRT、VTT、JSON。
- **AI 配音**：分段设语言、音色、停顿，音色克隆。
- **图片去 AI 元数据**：只清理文件元数据，不改像素。
- **图片转 Live 图**：本地生成动效。
- **账号运营规划**：维护账号的长期规划。

也可以在对话里让 AI 做一个自己的小工具。

## 技能

- **内置技能**：Beav 自带一批创作技能（各平台写作、仿写、数字人口播、剪辑、商品卡、产品使用手册 `beav-guide` 等），AI 按任务自己选用。
- **在对话里用**：输入 `@` 选择技能，非单轮技能会在这个对话后续轮次持续生效（输入框上方显示「技能 · 持续生效」）。新对话页的场景也会挂上对应技能。
- **技能市场**：搜索、安装技能；也可输入 GitHub `owner/repo` 安装仓库里的 `SKILL.md`。
- **保存方法为技能**：在对话里让 AI 把确认好的方法整理成技能，可存为用户级（跨空间）或只在当前空间。
- 技能依赖的 Node、Python 等运行环境不会自动安装。

## 插件

「插件 → 我的插件」管理已安装插件（启停、卸载）。

- 推荐插件可直接安装：Remotion（AI 做代码动画）、HyperFrames（HTML 视频）、ComfyUI Local、Comfy Cloud、RunningHub · Pixelle 等。
- 也可从 GitHub 安装带插件清单的仓库，或导入本机 Codex 插件。
- 插件里的 MCP 连接默认关闭，需要在「我的插件」里启用并测试。

## MCP 连接与环境变量

- 可以添加自定义 MCP 连接（本机命令或远程地址），让 AI 使用外部工具服务。
- **环境与密钥**：统一保存第三方 API Key 和环境变量，可用 `.env` 批量编辑，按变量决定 Beav Agent 和外部 Agent 能否使用。AI 可以在一次任务或可复用的 JavaScript 脚本里按需读取。
