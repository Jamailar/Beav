这里按 App 的板块，一篇文档讲一个板块：它是干什么的、从哪进入、里面有什么、和其他板块怎么配合、东西存在哪。写给想快速理解 Beav 的人和 AI（例如在这个仓库里工作的编码 Agent、接入 Beav 的外部 Agent）。

- 事实以当前 `main` 源码和 App 内置的产品手册为准。部分功能随下一个版本发布，正式安装包里可能还没有。
- 这里只讲"是什么、在哪、怎么配合"，不写逐步操作和排错。详细步骤见官网教程 <https://beav.pro/docs>。
- 账号权益、模型价格、积分单价以 App 和服务端实时返回为准，这里不写死数字。

## Beav 是什么

Beav 是「自媒体 AI 工作台」：一个桌面 App（Tauri + Rust + React），把收集对标内容、积累自己的素材、和 AI 对话创作、剪辑、打包发布放在同一个地方。核心思路是**积累即壁垒**：存下来的参考、拆解出的方法、自己的素材和风格，会被 AI 在之后的每次创作里用上。

典型流程：手机刷到好内容 → 分享到电脑存进参考库 → 拆解学方法 → 在对话或创作页里让 AI 用自己的素材做一版 → 打包成各平台的发布包 → 扫码到手机发布。

## 三个库怎么分

判断一样东西放哪，只问两件事：它是不是一篇完整的内容？是谁的？

| | 是什么 | 例子 |
| --- | --- | --- |
| 素材库 | 自己的、可以拿来做内容的零件 | 图片、视频片段、文案片段、配乐、提示词、选题、数字人、商品与店铺；导入的电脑文件夹、Obsidian、Eagle |
| 我的作品 | 自己的完整内容 | 自己账号的档案和已发作品；自己的稿件和各平台发布包 |
| 参考库 | 别人的完整内容和别人的账号 | 收藏的小红书/抖音/YouTube/X/公众号等单篇内容；订阅博主抓到的内容；拆解出的碎片 |

常见判断：自己写好的一篇笔记在「我的作品」；从别人视频里切出一个镜头存下来后在「素材库」；自己账号已发的作品在「我的作品」顶部的账号里，不在参考库。AI 生成的文件先进素材库里的「生成记录」，收藏后才算素材。

## 两种使用模式

- **Agent 模式**（默认）：完整的 Beav。
- **素材库模式**：收起对话和 AI 创作，只留素材库、参考库、我的作品、热点和日历，界面变成访达风格；素材入库后的 AI 理解（拆解、转写、索引）照常工作。适合把 Beav 当成带 AI 理解的素材库，交给自己常用的 Agent 用。见[接入外部 Agent 与素材库模式](external-agents.md)。

切换：设置 → 常规 → 使用模式（先弹窗确认，点「切换」后播放切换动画），或 ⌘⇧M / Ctrl+Shift+M（同样先确认）。模式是全 App 的，不跟空间走。
