# 账号、设置与记忆

## 账号菜单

左下角头像（显示当前空间的头像和名字）打开账号菜单：

- 账号信息和会员标签。
- **账号空间**列表和新建、管理空间，见[账号空间与初始化](spaces.md)。
- 外观、**使用模式**（Agent / 素材库）。
- 设置、会员、兑换码、推荐给朋友、接入 Agent、帮助与反馈。

## 会员与积分

- AI 调用（对话、生图、视频、配音、转写、社媒采集等）按积分计费；每条回复底部显示本次消耗。会员享折扣价，部分模型仅会员可用。
- 会员档位、价格、积分包以 App 内实时报价为准；分大陆区（beav.pro，人民币）和国际区（getbeav.com，美元）两个账号区。
- 积分不足时可开通会员或单独充值；兑换码在账号菜单里使用。
- 「推荐给朋友」生成专属邀请链接，朋友打开即带邀请码注册。

## 设置页

主要分区（具体以当前版本为准）：

- **账号**：登录、会员、订单。
- **AI 模型**：选择官方模型或自定义供应商（填 API 地址和 Key），按用途分别配置模型：对话与智能体、图片、视频、视频理解、配音、转写等；另有**决策模型**（小判断用的便宜模型，可选）和**自动化任务模型**（日报、自动运营、定时任务、记忆整理等后台调用用的模型）。
- **常规设置**：界面语言（中文 / English，AI 回复默认跟随）、已归档对话、代理等。
- **自动运营**：每日运营日报、账号档案定时刷新等「没操作也会花积分」的任务开关和配额；左侧账号按钮上方的小字提示和「查看每一笔」记录都来自这里。
- **个性化**：「AI 对你的了解」、启用记忆、从任务中学习。
- 其他：团队、电商平台、工具管理等；网页访问模式见[网页访问与服务器版](remote-access.md)。MCP 和环境与密钥见[工具&技能](tools-and-skills.md)。

## 记忆与创作风格

- **长期偏好**：在对话里说「以后默认这样」，并说明适用范围（当前空间所有创作、某个平台的所有账号、或当前账号）。只要求这一次不会变成长期默认。
- **记忆按空间隔离**，后台定期整理（有新内容才整理，结果用自动化任务模型）；设置里可以查看、关闭或重置。
- **多种写作风格**：每个空间的写作风格可以保存多种写法（共通原则 + 各种风格规则 + 认可的范例），AI 按当前栏目和内容形式挑选，不把所有内容套成一种写法。初始化时从你的账号内容学出第一版。
- **账号规划**：栏目方向、频率和目标，日报按它推荐选题。

## 关闭窗口

默认关闭主窗口只是隐藏，Beav 在后台继续运行（本机端口 `127.0.0.1:31937`、素材库网页、外部 Agent 的 MCP 和后台任务都可用）；从托盘或菜单退出才真正退出。
