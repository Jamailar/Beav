# 热点

## 定位

热点页把全网和各平台的热搜榜单拉到 Beav 里，并按当前空间的账号定位打分排序，帮你找能蹭的话题。数据来自 NewsBing（Beav 的热点与资讯服务）。

## 入口

左侧「热点」。素材库模式里也保留。

## 连接 NewsBing

首次打开不显示榜单。点「前往授权」在浏览器打开 NewsBing 授权页，登录后点「授权给 Beav」：NewsBing 为你创建一枚个人只读 API Key，加密回传给 App，存进本机系统凭据库，不用手动复制。网页没能跳回时，可以复制授权链接回 App 粘贴完成。标题栏「更多」菜单里可以管理授权或断开连接。

## 页面内容

- **主列表**：默认「适合我」，AI 用当前对话模型给总榜靠前的候选打账号关联度，再和热度合成综合分排序（热度 60%、关联度 40%）；也可切到「全网热度」只按热度看。
- **各平台热点**：按平台分区的榜单。
- **行业新闻**：AI 按账号定位，从 NewsBing 现有板块和方向词里挑最多 3 个板块、10 个方向词推荐给你；推荐方向可见、可改。
- 每条热点可「AI 讨论」，开一个围绕它的选题对话；素材库模式下换成「存为选题」。
- 打开时先显示上次成功加载的数据，超过两分钟在后台更新；刷新失败保留旧数据。

## 和其他板块的关系

- 日报的「今日选题参考」也会读 NewsBing 热点，见[主页](home.md)。
- 在对话里明确要选题且涉及当前热点时，AI 也会从 NewsBing 找线索，再读原文核验。
- 热点存为选题后出现在素材库「选题」和主页选题池。
