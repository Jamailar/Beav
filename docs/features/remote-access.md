# 网页访问与服务器版

## 定位

除了桌面 App，Beav 也能在浏览器里使用：要么让桌面端开放网页访问（在可信局域网里用手机或另一台电脑打开），要么把 Beav 装在 Linux 服务器上长期运行。浏览器里看到的是和桌面版相同的页面和功能。

## 桌面端开启网页访问

在设置里打开「网页访问模式」，之后可在本机和可信局域网设备的浏览器中使用 Beav；支持手机扫码登录（二维码 5 分钟内有效、只能用一次），可修改管理员账号密码。只在可信网络里开启。

## Linux 服务器版

- 支持 Debian 12+ / Ubuntu 22.04+ 的 x86_64 主机。
- 安装：`curl -fsSL https://beav.pro/install.sh | bash`，装成 `beav-web` 服务；浏览器打开安装器打印的地址，用 `admin` 和首次显示的管理员密码登录。
- 和桌面版的差别只在需要操作服务器本机系统的动作（例如打开本机文件夹、系统文件选择）。
- 需要从互联网访问时，先限制 Beav 端口，再用受控的 HTTPS 反向代理转发，并只信任自己的代理。

## 和「本机素材库网页」的区别

`127.0.0.1:31937/library` 只是素材库 / 参考库 / 我的作品的浏览整理页，主要给外部 AI 工具的侧栏用，见[接入外部 Agent](external-agents.md)。网页访问 / 服务器版是完整的 Beav。
