# 创作页

## 定位

「创作」页放的是**内容模板**：把一条你想照着做的内容（视频、图文或文章）做成模板，之后选模板、填几项，就能做出结构和风格高度相似、但内容是你自己的新作品。适合不想每次从头描述要求的人。

页面副标题就是它的用法：选一个模板，填几项，剩下的交给对话去做。

## 入口

左侧「创作」。

## 用模板

1. 选一个模板，在抽屉里填几项（主题、出镜、数字人、声音、商品、画面做法、时长等，每个模板只问它需要的）。必填项在前，选填项收在「更多选项」里。
2. 点「开始做」，新建一个对话，AI 按模板和你的选择接着做。之后的过程都在对话里，想改哪里直接说。
3. 表单里选过的不会再问；只有要花积分的步骤（生成视频、数字人、配音等）和缺必需材料时才会停下来确认。

标题栏右侧「N 个运行中」列出从创作页发起的对话（含正在拆解、等视频下载的），点一条进入对应对话。「生成选题／自动出选题」这类后台运行本身没有对话，点开时才建一个放进左侧对话列表，写明这次的请求、进度、用时和结果（失败原因或选题清单）。

## 模板里写了什么

模板来自拆解时得到的「形式迁移理解」（见[参考库](references.md)的拆解），分三栏：

- **会照着做**：结构、开头、节奏、句式、画面或版式风格，带具体数字。
- **需要你提供**：也就是表单字段。
- **不会照搬**：原作者的人物、品牌、数据、原片画面。

视频模板还带「风格学习」结果：画面由哪几类组成、版式字幕、动画、插画画风、剪辑节奏和配色，每类画面一张从原片截的参考帧（只当风格参考，不进成品）。

支持的体裁：口播、AI 动画讲解、AI 混剪讲解、图文笔记、文章。剧情、舞蹈、纯音乐类内容不做成模板。

## 新建模板

- 「新建模板」卡片：「输入链接」（先存进参考库）或「从参考库添加」；参考库卡片右键也有「做成模板」。
- 做成模板前必须先拆解：没拆过会提示视频时长和计费方式，确认后在后台拆解；拆完自动开一个「做成模板」对话。
- 生成的模板以「草稿」出现在「我的模板」，检查三栏和表单字段后点「保存，可以用了」才能使用。
- 模板自动有封面（原内容封面 → 第一个镜头 → 风格参考帧）。卡片右键：使用、编辑、重命名、复制一份、打开原内容链接、删除。

## 微调与更新模板

- 只改这一次：表单里的「这次的微调」，或开始后在对话里直接说。模板不变。
- 以后都这样：在对话里说「存进模板」，AI 把改动写进模板，模板回到草稿，确认后生效。想保留原模板就先「复制一份」或说「另存一份」。

## 存放位置

模板存在当前空间的 `templates/content/`，跟空间走；共享空间暂不支持。
