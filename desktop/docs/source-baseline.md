# 2.5.0 源码基线与历史

核对日期：2026-10-06。适用范围：本仓库公开 Tauri 2.5.0 源码。

- 基线来自 2026-06-25 的 2.5.0 开发提交；原内部提交标识为 `58a9a633c3047353c22f3bc6ce1e68dd1f0f98ac`，清理后为 `ce73783930ca38c9d53a6ee11a6ccc52ca02e5f1`。
- 完整保留该基线之前的开发提交、作者、提交时间、说明及父子关系。历史中的 Tauri `LexBox/` 目录统一映射为 `desktop/`。
- 旧 Electron 实现及其归档、内部文档、本机配置和依赖缓存从可达公开历史中移除。清理改变了 Git 提交哈希。
- 原公开仓库的发布、文档和图片历史保留；其中混入的其他版本应用源码被移除。2.5.0 应用源码历史以本次导入的开发历史为准。
- `v2.5.0` 源码标签指向清理后的真实 Tauri 基线。后续 Release 提供的正式安装包继续独立更新，其版本不代表公开源码版本。
- 后续公开文档与图片从私有维护仓库生成 PR，经 GitHub 审查合并；该流程不会同步后续私有应用源码。

源码包含前端、Rust 宿主、浏览器扩展、构建配置和运行资源。第三方 FFmpeg/FFprobe 二进制、依赖安装目录、构建产物、服务端实现、生产凭证及签名私钥不在源码范围内。

验证区分：此次核对覆盖 Git 对象完整性、源码及资源引用、敏感信息扫描，以及前端和浏览器扩展构建。此次没有重做三平台签名、公证、安装包验收或真实业务回归；第三方账号和线上服务需要使用者自行配置并验证。
