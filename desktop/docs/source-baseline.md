# Beav 源码版本与提交历史

公开源码版本为 **2.6.0**，对应 2026-07-03 发布前的构建源码。桌面端和浏览器扩展均为 2.6.0。可用 `source-v2.6.0` 获取固定版本。GitHub [v2.6.0 Release](https://github.com/Jamailar/Beav/releases/tag/v2.6.0) 提供当时发布的安装包。

开发历史接续现有的 `v2.5.0` Tauri 基线 `ce737839`。本次导入 68 笔提交，保留原作者、提交时间、说明和顺序。其中 5 笔只涉及公开范围以外的文件，以空提交保留记录。Git 根据公开文件树和父提交生成提交哈希。

公开源码包括桌面端前端、Rust 宿主、构建设置和锁文件、内置技能、提示词、运行资源以及配套浏览器扩展。构建所需的 FFmpeg 和 FFprobe 随平台单独准备，步骤见[构建说明](../README.md)。

2.5.0 的 Tauri 历史源自 2026-06-25 的开发基线。该次导入已将历史中的 Tauri `LexBox/` 目录统一映射为 `desktop/`，并清理旧 Electron 实现、内部文档、本机配置和缓存。公开文档、发布和图片的独立历史仍可在仓库中查阅。
